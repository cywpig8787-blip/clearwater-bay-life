# CYW-51：Point Pools v0.1 與住宿分配時機

正式規格：[Linear CYW-51](https://linear.app/cyw900704/issue/CYW-51)，2026-09-23 10:27:12 UTC 更新版本。實作前已讀取完整本文與全部 4 則留言；以最新「Point Pools v0.1」及「正式創角後續修正｜宿舍選擇時機」為準。

## 範圍與資料

- 延續原有創角步驟、技能清單、選校資格、家庭與經歷、肖像 placeholder；沒有修改 `world.mjs`、地圖配置或 CYW-58 介面重構。
- 六項能力值合計可分配 250，完成一般創角前必須分配完；單項最高 65。技能單項最高 75，技能點可不花完。
- Academic Base 200 用於原有學科清單，General 200 用於原有其他技能清單。
- 六項加成分別只建立一個來源，公式 `max(0, Attribute - 50)`。零與低能力值都不影響固定基礎點。
- 使用容量受限的來源→技能分配，能重新分配重疊來源，避免 INT 在學術與程式之間重複發放，也避免簡單貪婪配置誤判點數不足。
- 每次數值輸入即時計算；可展開查看各來源額度、已用／剩餘、公式、可投技能與實際分配。降低能力值時保留技能數值並顯示缺額，未修正不能完成創角。
- Developer Override 保留並明確標示；只有配點回到一般限制後才能關閉。一般完成流程另做完整驗證，舊草稿也不能繞過限制。

## 住宿分配

創角輸出仍沿用原本 Player State 儲存結構，性別值正規化為 `male / female / neutral`；移除舊草稿殘留的實際住宿欄位。

新角色從南門進入開學前一週，三種性別都處於 `pending`。到既有的主校舍 1F 行政中心，男性／女性按「辦理住宿分配」後固定分配對應側；中性在此處才出現男／女側選擇。

完成後寫入世界狀態的 `residentialAccess / residenceId / buildingId / floorId / roomId / bedId`。分配前不能進入住宅門禁；分配後不能跨側或跨棟。保留舊有效校園存檔，新角色不繼承創角階段的舊側別。
