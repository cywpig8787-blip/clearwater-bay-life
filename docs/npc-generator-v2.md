# 純外貌角色生成器：精簡重修

入口仍為 `web/npc-generator/`，Pages 網址不變。資料版本 4，沿用原 localStorage key。

正式欄位僅 12 項：身高、體型、膚色、臉型、眼型／形狀、瞳色、眉毛、鼻子、嘴唇、頭髮、辨識特徵、穿搭風格。眼型與瞳色依使用者後續要求分開。身高不指定公分；沒有身體比例或細部人體操作欄位。

`catalog.mjs` 提供整理過的完整視覺描述，眼型不獨立骰大小、眼角與眼皮；髮型的剪裁／捲度／可見細節已人工組合，再搭配受控髮色。`fashion.mjs` 保留既有 63 個風格方向並新增 5 個，移除整套衣服、配色、鞋與配件資料。`rules.mjs` 限制突出輪廓總量與小巧體型的身高相容性。正常人體差異不因美醜而排除。

辨識特徵：62% 無標記、35% 一個、3% 兩個。雙特徵不同類別且不都在臉部。沒有耳後或手背等高頻隱藏細節。

生成、單抽及鎖定只操作這 12 項。单抽只改該項；鎖定值限制其他項的相容選項。最近 8 次避重在可用選項內進行。複製與匯出使用相同五組、12 行格式。

v2/v3 的旧字段僅由 migration reader 讀取，用於轉成簡潔外貌。沒有舊 pool 或隱藏生成；保存後 values／locks／recent／history 只包含正式欄位。無法完整轉換的舊歷史不再顯示；目前人物缺少欄位時補齊且保留已轉換值。v4 資料以白名單重建，拒絕額外屬性與任意文字。

UI 為五個分組的緊湊列；初始和清空時顯示一句操作提示，隱藏尚未生成的結果，不顯示「？？？」。本機自動存取、歷史、鎖定、單抽、複製及文字匯出保留。

驗證包含 10,000 次生成、輸出密度與多樣性、全欄單抽與隨機鎖定、旧格式遷移，以及瀏覽器操作／下載／剪貼簿／320–1536px／手機結果高度。
