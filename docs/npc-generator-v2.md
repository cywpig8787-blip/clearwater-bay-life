# 純外貌角色生成器（原 v2 入口，資料版本 3）

入口仍為 `web/npc-generator/index.html`；Pages 上傳 `web/`，網址不變。

資料流：`app.mjs` → `engine.mjs` → `catalog.mjs`（視覺詞彙）、`fashion.mjs`（衣服／配色／鞋／配件）、`rules.mjs`（相容性）。30 個欄位，全部參與畫面與匯出。沒有隐藏的生活或人物欄位；`retained.mjs` 與舊可執行備份已移除。

突出特徵總量最多 2，眼部最多 1；這是輪廓強調程度，不以膚色、體型、單眼皮、鼻翼寬度等正常差異評判美醜。痣等記號的抽樣為 0 個 50%、1 個 40%、2 個 10%；兩個記號不能同類或都在臉部。自然髮色 75%、整理過的染髮色 25%。這些是生成權重，不是人口統計。

髮長限制瀏海、分線、綁法；捲髮限制瀏海；服裝風格限制穿搭、配色、鞋及配件。配件 0–1 件。沒有性別推導，也不從穿搭推導背景。

鎖定值先保留，再以相容選項抽取其他欄位。父欄位重抽只更新未鎖定的依賴項；若無替代選項可保持原值。近期 8 次避重僅在相容池內進行，不能凌駕約束。失敗為交易式，不部分修改人物。

沿用 localStorage key `cbl-npc-generator-v2`，內部版本升至 3。舊 current、history、recent、locked 全部以現行資料池白名單重建，不信任舊標籤或附加屬性。不再存在的詞條不保留，空缺由下一次生成補齊。原存檔會被清理後的版本取代。歷史最多 100 次，清空人物不清歷史。

驗證：`node --test tests/npc-generator.test.mjs tests/npc-generator-controls.test.mjs`。包含 10,000 次生成、覆蓋率與辨識點分布、隨機鎖定子集及每欄單抽、重載、舊資料清理與交易失敗。網站互動另以實際瀏覽器驗證。
