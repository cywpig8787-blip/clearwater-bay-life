# Ravenwood 文本移動 v0.1

入口：`web/opening/` 完成現有創角 → 選 Ravenwood → 住宿分配 → `web/ravenwood/`。
以 HTTP 伺服器提供 `web/`（ES modules 不支援直接雙擊 file://）。不需要套件安裝或建置。

這是 repository 約定的 Web UI/UX 測試版本；Godot 專案仍是原有空殼，尚未移植此玩法。
原有 `web/game/` 房間操作測試、手機 OS、角色圖片／placeholder 均保留。

## 空間來源與距離

- 依使用者提供的 [P-CYW-5 校園總平面原圖](../../docs/references/ravenwood-campus-original.png)（360 × 320 m）建立室外連接，不重畫地圖。座標原點採圖左上角，向右／下為正，不推定地理北方。
- 圖內舊註記的樓層數以本次已確認文字規格覆蓋：主校舍 5F，科學翼 3F，音樂中心 3F，宿舍 9F。
- 室外 `position` 為圖上公尺座標；`path()` 沿圖示步道折線求長度，非穿越建築的直線距離。
- 圖上的大型公園僅示意 120 m 深度，商店街未定尺度；此兩段採圖上比例估算 60 + 86 m，屬第一版邊界接口，並非已確定的城市規劃。
- 室內没有完整尺寸圖；走廊、房門等距離是依建築外框作的可調估值。每層樓梯行走長度 8 m、樓高 3.6 m。教室門依序分布，每間 30 席。科學翼以本體連接連到主校舍 1–3F，其他棟沒有空橋。
- 步行 1.3 m/s（原圖亦採此速度）；樓梯 0.65 m/s；電梯 1.5 m/s + 20 秒候梯。每條邊以 `ceil(距離 / 速度 + 候梯)` 計秒，不把短程強制進位為分鐘。速度集中於 `world.mjs` 的 `movement`。
- `world.mjs` 為資料建構器，輸出純 `locations` / `connections`；UI 與移動引擎不寫死目的地。每個連接雙向，目的地條件由引擎再次驗證。
- 泛用戶外活動區與網球場依已確認文字掛到戶外體育入口，尚無個別測量圖，不宣稱是實測距離。

## 住宿與門禁

使用者在本次實作確認 08／10 男側、09／11 女側；08–09、10–11 各有一個 3F 共享區。
男性固定男側、女性固定女側；只有中性在住宿頁選擇側別。第一版測試分配到對應側第一棟（08 或 09）201 雙人房；這是測試預設，並非新增正式住房政策。
模板支援四棟，既有有效 `buildingId` 可保留。四棟 1F 公共區可進入，住宅層需同時符合 `buildingId` 與 `residentialAccess`。
1F 門禁放在樓梯／電梯前，3F 共享區的每一側住宅出口也檢查權限，沒有跨側捷徑。
每棟 2、4–6F 各 6 雙人房，7–9F 各 7 單人房；1、3F 無學生房。

## 狀態與測試規則

- 保留創角原本 `clearwater-life-player-state-v1` 的 `{saveVersion,createdAt,player:s}` 結構，只增住宿資料。
- 新校園狀態使用獨立 `clearwater-life-ravenwood-v1`，不覆蓋既有 `clearwater-life-game-v1` 或手機資料。
- 以角色 `createdAt` 識別新角色；重新整理續玩同一角色。重新按「建立角色」才重開校園。舊角色缺住宿側時回創角補選，不擅自分配中性側別。
- 開學日 2026-09-01、起始 2026-08-25 09:00 為本次固定測試日期；只依玩家移動／判定推進時間，跨日正確進位。開學日後仍為自由測試，沒有暗加課表或事件。
- 共享會議室需在門外預約，本版採本次測試期間有效的簡單名單。尚無時段排程／NPC 占用。
- 置物櫃用既有「妙手」，不新增角色技能。d100 ≤ clamp(25 + 妙手, 5, 95) 成功，兩種結果均耗 120 秒。參數集中 `engine.mjs/checkConfig`。
- 自己的櫃子無判定；其他學生櫃成功後可重開存取接口，失敗記錄被發現。櫃內暫空，不生成物品或額外懲罰。Development Check 開關只控制顯示。
- Actions／People／Items 都留資料接口；人物行程、背包、正式預約與學期事件尚未接入。
